# icons/ — app icons

Brand mark: right-facing **swastik** with operators `- + x /` in the four pockets on teal `#0f3d3e`.

| File | Use |
|------|-----|
| `icon-192.png` / `icon-512.png` | PWA / apple-touch |
| `favicon.png` | Tab favicon |
| `icon.svg` | Vector source |

Regenerate via `python scripts/generate_icons.py` (or `npm run icons`).

Referenced from `index.html`, `manifest.webmanifest`, and UI logos (sidebar / boot / book gate).
